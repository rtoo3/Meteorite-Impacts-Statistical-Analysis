# Statistical Analysis of Meteorite Landings

## Overview

This project applies statistical analysis and data visualisation techniques to a dataset of meteorite landings.

The analysis explores patterns in meteorite landings using Python and Jupyter Notebook, with a focus on descriptive statistics, distributions, relationships between variables, geographical patterns, and statistical analysis.

## Objectives

The project investigates the meteorite landing dataset through a series of statistical questions and visual analyses.

The analysis includes:

- Exploring the distribution of meteorite masses
- Examining relationships between meteorite variables
- Comparing groups within the dataset
- Analysing geographical patterns in meteorite landings
- Investigating differences between hemispheres
- Applying statistical methods to draw conclusions from the data
- Using visualisations to communicate statistical findings

## Dataset

The analysis uses the **Meteorite Landings** dataset.

The dataset contains information about recorded meteorite landings, including variables relating to meteorite characteristics and geographical location.

## Tools and Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Statistical Analysis
- Data Visualisation

## Analysis

The project consists of nine statistical questions covering different aspects of the meteorite landing data.

The analysis uses a combination of:

- Descriptive statistics
- Data visualisation
- Distribution analysis
- Correlation analysis
- Group comparisons
- Geographical analysis
- Statistical hypothesis testing

Each question includes visualisations and statistical interpretation of the results.

## Visualisations

The project includes a range of visualisations, including:

- Box plots
- Scatter plots
- Bar charts
- Histograms
- Line plots
- Geographical maps

These visualisations are used to identify patterns, compare groups, and communicate the results of the statistical analysis.
